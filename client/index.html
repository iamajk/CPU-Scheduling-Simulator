Understanding CPU scheduling algorithms

What is CPU Scheduling?

CPU scheduling is the process by which the OS decides which process in the ready queue gets the CPU. A good scheduler maximises CPU utilisation while minimising waiting and response times.

FCFS

Processes run in arrival order. Simple but can cause the convoy effect.

✔ Simple, fair✘ High avg WTBatch processing

SJF (NP)

Shortest burst runs first. Optimal avg WT for static batch.

✔ Min avg WT✘ StarvationBatch systems

SRTF

Preemptive SJF — preempts if newcomer has shorter remaining burst.

✔ Optimal avg WT✘ High context switchesInteractive systems

Round Robin

Fixed time quantum rotation. Fairness + responsiveness.

✔ Fair, responsive✘ Quantum choice criticalTime-sharing OS

Priority (NP)

Highest priority (lowest number) runs to completion.

✔ Critical tasks first✘ Starvation possibleReal-time systems

Priority (Pre)

Higher-priority arrivals preempt running process immediately.

✔ Very responsive✘ High switch overheadOS kernels
